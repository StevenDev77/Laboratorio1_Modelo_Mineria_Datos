Metodología SEMMA Aplicada

1. SAMPLE
529 registros etiquetados, 144 seguros. Partición 70/15/15 estratificada.
2. EXPLORE
Estadísticas descriptivas, conteo por lenguajes y desbalance de clases.
3. MODIFY
FeatureUnion: TF-IDF (2500) + Rasgos sintácticos de seguridad (16).
4. MODEL
Comparación: Random Forest, Linear SVM y Regresión Logística (Sin LLMs).
5. ASSESS
Evaluación ciega sobre 80 registros. F1 Macro: 1.000, 0 Falsos Positivos.
